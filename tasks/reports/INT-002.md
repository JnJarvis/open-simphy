## Delivered scope

Accepted editor v1 implemented under src/editor: owning State, checked View and
physical-pixel picking, add/replace/erase/gravity edits, selection, 64-transition
undo/redo, monotonic session watermark and baseline-relative drag preview/commit/
cancel. Editor dependencies remain core/math/scene only. Headless root module list
now includes editor independently of APP/SDL; public header compiles in isolation.

App integrates the editor with explicit Authoring/Simulation modes. Play enters
Simulation, Step advances once, Reset stops and returns to Authoring; paused
advanced simulation rejects editing. Candidate editor and World are prepared
before publication, with injected World-creation failure coverage. Selection
highlight uses scene overlay lines; world geometry still belongs to CPU renderer.

Native UI offers toolbar Play/Step/Reset/Add/Undo/Redo, click selection/dragging,
Delete, numeric mass/position/velocity/radius/gravity entry, Ctrl+Z/Y, scroll zoom,
WASD pan, error/status text and scrolling property fields. SDL text input and
SDL debug text avoid a new toolkit/font dependency. This is a functional minimal
particle editor, not a full-featured CAD/editor UI or persistence implementation.

The canvas excludes the properties panel. Host copies frame to an explicit equal-
size destination rectangle, never stretches to fill the entire window. Physical
pointer normalization uses output/window ratios independently for x and y. UI uses
reported display scale; world remains physical pixels/meter. Focus/resize/scale
changes cancel active drag before changing view. SDL stays private to app.
