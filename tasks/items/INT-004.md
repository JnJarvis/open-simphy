# INT-004 — Open real SSIM archives and inspect their contents

User explicitly prioritizes working SSIM opening over further planning. Implement
an app Open/Ctrl+O/file-drop/command-line action backed by a portable headless compat
reader. This is source-project inspection, not particle conversion or runnable
rigid-body import. Current scene remains untouched on parse failure or cancel.
Retain source bytes; show project title/version and discovered body/shape/joint,
script/asset/other-domain counts plus clear unsupported behavior. No Play of source
projects until required engine support exists. Return to authored demo explicitly.

Allowed: src/compat/; src/app/; tests/compatibility/ssim/; CMakeLists.txt;
cmake/OpenSimSSIM.cmake; cmake/OpenSimSDL.cmake; spec/contracts/ssim-reader.md;
docs/ssim.md; docs/demo.md; README.md.
Dependencies: COMPAT-004, INT-003. Read README, tasks/README, architecture/testing,
SSIM inspection and migration RFC. Document new pinned ZIP/XML private dependencies
and notices. Keep compat free of paths, native handles and scene/physics mutation.
Expose only bounded byte-input/owning inspection result; no shared scene changes.
Record the new reader API explicitly in spec/contracts/ssim-reader.md before code.
Default headless and no-tests engine configurations must avoid importer downloads.

Required tests: stored/deflated real XML; malformed ZIP/CRC/truncation, unsafe and
duplicate names, unsupported version, missing XML, DTD/depth/size/element bounds,
nested compound bodies, multiple fixtures, scripts, unknown content; deterministic
counts and ownership; valid-invalid-valid open preserves the previous source.
Test all 67 local archives without copying them into Git. Real native smoke must
open a real source, display its report, reject corrupt input and return to editing.
Run affected/full checks, formatting and native CI; submit review with working app.
