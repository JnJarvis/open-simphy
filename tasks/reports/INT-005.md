## Delivered

Neutral grayscale UI panels, controls, highlights, source outlines and viewport
background. Canonical renderer Frame bytes/object colors are preserved; host
recolors clear pixels only after decorating grid lines in its own upload copy.
Scalable, antialiased Noto Sans replaces SDL debug text. FreeType rasterizes glyphs
at physical display density; glyph cache rebuilds on density changes, bounded to
2048 entries. Width clipping uses measured advances and UTF-8 code points. Source
labels no longer replace non-ASCII bytes with question marks. Unsupported font
characters use the font's missing glyph. Font loads via SDL bytes, not OS-specific
font paths; resources are beside the executable, independent of launch directory.
